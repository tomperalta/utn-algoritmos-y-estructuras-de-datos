# Resolución

## Estrategia general

El archivo viene **agrupado por película**, de modo que todo el proceso es un
**corte de control por un nivel**: cada vez que `ProcPelicula()` se invoca,
consume el grupo completo de una película, acumula sus boletos y deja el
registro `rPeli` posicionado en el **primer registro del grupo siguiente** (o en
el centinela). Eso es lo que permite que el ciclo de `main()` sea 0-x y pregunte
únicamente por `cadenaCine[0] != '*'`.

```
                       ┌───────────────────────┐
     Peliculas.Txt ───►│  ObtDatos(rPeli)      │  lee 1 registro (lectura adelantada)
                       └───────────┬───────────┘
                                   ▼
                       ┌───────────────────────┐
                       │  ProcPelicula(...)    │  corte de control por pelicula
                       │  ├ acumula boletos    │
                       │  ├ CalcCantSem(...)   │
                       │  └ InsertaEnOrden(...)│  mantiene el top-10 ordenado
                       └───────────┬───────────┘
                                   ▼
                       ┌───────────────────────┐
                       │ ListadoRankPeli(...)  │───► Ranking10Peli.txt
                       └───────────────────────┘
```

**Invariante del proceso:** `vrRank[0..cantPeliculas-1]` está **siempre ordenado
por `totBoletos` en forma descendente**. Lo establece `InsertaEnOrden()` en cada
alta y por eso el punto 3 se limita a emitir, sin volver a ordenar.

## Ejercicio 1.a — Estructuras de datos

### Dibujo de `tsPeli` — registro de entrada

Un registro del archivo = **una película exhibida en una sala de un cine**.

```
             ┌──────────────────────────────────────────────────────────────┐
tsPeli       │ cadenaCine     str20   "Cinemark"                     21 by  │
             │ cine           str20   "Cinemark Palermo"             21 by  │
             │ nroSala        ushort  1..99                           2 by  │
             │ pelicula       str30   "Toy Story 4"        ◄ CLAVE   31 by  │
             │ (relleno de alineacion del uint que sigue)             1 by  │
             │ fechaEstreno   uint    aaaammdd -> 20190620            4 by  │
             │ cantBoletos    ushort  vendidos en ESA sala            2 by  │
             │ capacidadSala  ushort  butacas de la sala              2 by  │
             │ calificacion   char    'A' | 'B' | 'C' | 'D'           1 by  │
             │ idioma         str15   "Doblada" | "Sub-titulada"     16 by  │
             │ imagen         str5    "2D" | "3D" | "4D" | "IMAX"     6 by  │
             │ (relleno final del registro)                           1 by  │
             └──────────────────────────────────────────────────────────────┘
                                                          total = 108 bytes
                                                     (106 utiles + 2 relleno)
```

*Cómo se genera:* lo llena `ObtDatos()` leyendo una línea de `Peliculas.Txt`.
*Estado inicial:* indefinido; la primera lectura la hace `main()` antes del
ciclo. *Fin de datos:* el registro centinela, con `cadenaCine[0] == '*'`; en el
centinela **los demás campos no se leen y por lo tanto no deben usarse**.

**Detalle importante:** cada registro trae `cantBoletos` de **una sola sala**.
El ranking se arma por película, así que hay que sumar todos los registros del
grupo. `cadenaCine`, `cine`, `nroSala`, `capacidadSala`, `idioma` e `imagen` se
leen porque forman parte del registro de entrada, pero **no intervienen en este
listado** (servirían, por ejemplo, para calcular el porcentaje de ocupación
`cantBoletos / capacidadSala`).

### Dibujo de `tsRank` — registro de la tabla de ranking

Contiene exactamente lo que pide el listado del punto 3, ya resumido por
película. `nro.Orden` **no es un campo**: es la posición `i+1` dentro del array.

```
             ┌──────────┬────────────┬──────────────┬─────────────┬──────────┐
tsRank       │ pelicula │ totBoletos │ fechaEstreno │ cantSemanas │ calific. │
  44 bytes   │  str30   │    uint    │     uint     │   ushort    │   char   │
             │  31 by   │    4 by    │     4 by     │    2 by     │   1 by   │
             └──────────┴────────────┴──────────────┴─────────────┴──────────┘
              "Toy Story 4"  41500      20190620          1           'A'
                  ▲              ▲                            (+1 by de relleno
                  │              │                             antes de totBoletos
               columna 2     CLAVE DE ORDENAMIENTO             y 1 by al final)
                             descendente
```

**Detalles importantes:**

* **`totBoletos` es `uint`, no `ushort`.** `cantBoletos` de un registro cabe en
  un `ushort` (≤ 65.535), pero el **acumulado** de una película en todas las
  salas de todas las cadenas lo desborda con facilidad. `uint` da hasta
  4.294.967.295 y ocupa 4 bytes en cualquier compilador.
* Los campos se **declaran** en orden `pelicula, totBoletos, fechaEstreno,
  cantSemanas, calificacion` para que el relleno de alineación sea mínimo
  (44 bytes en lugar de 48). El orden de declaración es independiente del orden
  de las columnas del listado.
* `cantSemanas` se calcula **una sola vez por película**, al cerrar el grupo, y
  queda guardado: `CalcCantSem()` no se vuelve a invocar al emitir.

### Dibujo de `tvrRank` — la tabla de ranking

```
                     0          1          2                     8          9
              ┌──────────┬──────────┬──────────┬─ ─ ─ ─ ─┬──────────┬──────────┐
vrRank        │  1er     │  2do     │  3er     │         │  9no     │  10mo    │
[MAX_RANK]    │ tsRank   │ tsRank   │ tsRank   │         │ tsRank   │ tsRank   │
              │ 44 bytes │ 44 bytes │ 44 bytes │         │ 44 bytes │ 44 bytes │
              └──────────┴──────────┴──────────┴─ ─ ─ ─ ─┴──────────┴──────────┘
              └───────── ORDENADO POR totBoletos EN FORMA DESCENDENTE ─────────┘
              └─── cantPeliculas ───┘
                  (ocupacion real)

              MAX_RANK = 10   ->   total 10 x 44 = 440 bytes
```

*Estado inicial:* `cantPeliculas = 0`; el contenido del array es basura y **no
se toca** hasta que se inserta la primera película. *Cómo crece:* una posición
por película distinta, hasta 10. A partir de ahí la tabla **no crece más**: una
película nueva sólo entra si supera a `vrRank[MAX_RANK-1]`, y en ese caso la
última se descarta.

**Detalle importante:** `cantPeliculas` es la **ocupación de la tabla** (0..10),
no la cantidad de películas leídas del archivo. Tiene que ser así porque
`ListadoRankPeli(vrRank, cantPeli)` la usa como límite del ciclo que recorre el
array: si valiera 12, se leerían posiciones inexistentes.

### Dibujo de `tsFecSys` — fecha del sistema

```
             ┌────────┬────────┬────────┬────────┐
tsFecSys     │  aaaa  │   mm   │   dd   │   ds   │
  16 bytes   │  int   │  int   │  int   │  int   │
             │  4 by  │  4 by  │  4 by  │  4 by  │
             └────────┴────────┴────────┴────────┘
               2019       7        1        1
                                          dia de la semana (0=domingo)
```

*Cómo se genera:* `GetDate(rFecSys.aaaa, rFecSys.mm, rFecSys.dd, rFecSys.ds)`,
una sola vez, en el bloque principal. Se pasa **por valor** a `ProcPelicula()`
porque sólo se consulta.

### Codificación de los tipos

```cpp
// ---------------------------------------------------------------------------
// Tipos que el lenguaje NO define y que usan los prototipos dados
// ---------------------------------------------------------------------------
typedef unsigned short ushort;
typedef unsigned int   uint;

#define record struct          // convencion de la catedra

// ---------------------------------------------------------------------------
// Tipos cadena (el +1 reserva el lugar del terminador nulo)
// ---------------------------------------------------------------------------
const ushort LARGO_IMAGEN  =  5;   // "2D" "3D" "4D" "IMAX"
const ushort LARGO_IDIOMA  = 15;   // "Doblada" | "Sub-titulada"
const ushort LARGO_CADENA  = 20;   // cadena de cines
const ushort LARGO_CINE    = 20;   // nombre del cine
const ushort LARGO_PELI    = 30;   // titulo de la pelicula

typedef char str5 [LARGO_IMAGEN + 1];
typedef char str15[LARGO_IDIOMA + 1];
typedef char str20[LARGO_CADENA + 1];
typedef char str30[LARGO_PELI   + 1];

const ushort MAX_RANK = 10;        // dimension de la tabla de ranking
const char   CENTINELA = '*';      // fin de datos en cadenaCine

// ---------------------------------------------------------------------------
// tsFecSys - fecha del sistema devuelta por GetDate()          16 bytes
// ---------------------------------------------------------------------------
record tsFecSys {
  int aaaa;
  int mm;
  int dd;
  int ds;                          // dia de la semana, 0 = domingo
};

// ---------------------------------------------------------------------------
// tsPeli - registro de entrada: una pelicula en una sala      108 bytes
// ---------------------------------------------------------------------------
record tsPeli {
  str20  cadenaCine;               // "*" en el registro centinela
  str20  cine;
  ushort nroSala;
  str30  pelicula;                 // clave de agrupamiento (corte de control)
  uint   fechaEstreno;             // aaaammdd
  ushort cantBoletos;              // vendidos en ESA sala
  ushort capacidadSala;
  char   calificacion;             // 'A' | 'B' | 'C' | 'D'
  str15  idioma;
  str5   imagen;
};

// ---------------------------------------------------------------------------
// tsRank - una fila de la tabla de ranking                     44 bytes
//   totBoletos es uint porque acumula los boletos de TODAS las salas de
//   TODOS los cines: el ushort de cantBoletos se desbordaria.
// ---------------------------------------------------------------------------
record tsRank {
  str30  pelicula;
  uint   totBoletos;               // CLAVE DE ORDENAMIENTO (descendente)
  uint   fechaEstreno;             // aaaammdd
  ushort cantSemanas;              // permanencia en cartel
  char   calificacion;
};

// ---------------------------------------------------------------------------
// tvrRank - la tabla de ranking            10 x 44 = 440 bytes
//   Invariante: vrRank[0..cantPeliculas-1] ordenado por totBoletos DESC.
// ---------------------------------------------------------------------------
typedef tsRank tvrRank[MAX_RANK];
```

### Bloque principal completo

```cpp
int main() {
  tsPeli   rPelicula;              // registro de entrada
  tvrRank  vrRank;                 // tabla de ranking
  tsFecSys rFecSys;                // fecha del sistema
  ushort   cantPeliculas = 0;      // ocupacion real de vrRank (0..MAX_RANK)

  freopen("Peliculas.Txt", "r", stdin);

  GetDate(rFecSys.aaaa, rFecSys.mm, rFecSys.dd, rFecSys.ds);  // ◄ LINEA A COMPLETAR

  ObtDatos(rPelicula);                                  // lectura adelantada
  while (rPelicula.cadenaCine[0] != CENTINELA)          // ciclo 0-x
    ProcPelicula(vrRank, rPelicula, cantPeliculas, rFecSys);

  freopen("CON", "r", stdin);
  ListadoRankPeli(vrRank, cantPeliculas);
  return 0;
} // main
```

> `cantPeliculas` **debe inicializarse en 0** antes del ciclo: es la ocupación
> de la tabla y `ProcPelicula()` la usa para decidir si hay lugar libre.

## Ejercicio 1.b — Diagrama de `ObtDatos()`

Los campos `cine` y `pelicula` contienen espacios en blanco, de modo que `cin >>`
no alcanza: cortaría el título en la primera palabra. El archivo se define con
los campos **separados por `;`** y cada cadena se lee con `getline` usando `;`
como delimitador; los campos numéricos se leen con `>>` y luego se descarta el
`;` que los sigue.

```
ObtDatos(rPeli)              ◄── rPeli por REFERENCIA: es el dato que devuelve
│
├─ leer rPeli.cadenaCine                    hasta ';'
│
└─ SI rPeli.cadenaCine[0] ≠ '*'  ENTONCES        ◄── seleccion simple
   │
   ├─ leer rPeli.cine                       hasta ';'
   ├─ leer rPeli.nroSala          + saltar el ';'
   ├─ leer rPeli.pelicula                   hasta ';'
   ├─ leer rPeli.fechaEstreno     + saltar el ';'
   ├─ leer rPeli.cantBoletos      + saltar el ';'
   ├─ leer rPeli.capacidadSala    + saltar el ';'
   ├─ leer rPeli.calificacion     + saltar el ';'
   ├─ leer rPeli.idioma                     hasta ';'
   └─ leer rPeli.imagen                     hasta fin de linea
   │
   FIN SI                        ◄── en el centinela NO se lee nada mas:
                                     el resto de la linea no existe
```

**Por qué no hay ciclo:** `ObtDatos()` lee **un solo registro**. La repetición
está afuera —en `main()` (0-x) y en `ProcPelicula()` (1-x)—, de modo que este
módulo tiene una única responsabilidad.

Codificación (complementaria al diagrama):


### Codificación

```cpp
// ---------------------------------------------------------------------------
// ProcPelicula
// Procesa UN grupo completo de registros: todos los de la misma pelicula.
// Acumula los boletos de todas las salas y de todos los cines, y luego intenta
// ubicar el resultado en la tabla de ranking.
//
//   Al entrar : rPeli contiene el PRIMER registro del grupo, leido por main()
//               o por la invocacion anterior de este mismo modulo.
//   Al salir  : rPeli contiene el PRIMER registro del grupo SIGUIENTE, o el
//               registro centinela si no hay mas datos.
//
// Esa lectura adelantada es lo que permite que el ciclo de main() sea 0-x y
// pregunte unicamente por el centinela.
// ---------------------------------------------------------------------------
void ProcPelicula(tvrRank vrRank, tsPeli &rPeli, ushort &cantPeliculas,
                  tsFecSys rFecSys) {
  tsRank rElem;                    // fila que se va a intentar rankear
  str30  peliDelGrupo;             // clave del corte de control

  // ---- cabecera del grupo -------------------------------------------------
  strcpy(peliDelGrupo, rPeli.pelicula);
  strcpy(rElem.pelicula, rPeli.pelicula);
  rElem.calificacion = rPeli.calificacion;
  rElem.fechaEstreno = rPeli.fechaEstreno;
  rElem.totBoletos   = 0;

  // ---- cuerpo del grupo: corte de control por pelicula (ciclo 1-x) --------
  do {
    rElem.totBoletos += rPeli.cantBoletos;
    ObtDatos(rPeli);                                  // lectura adelantada
  } while (rPeli.cadenaCine[0] != CENTINELA and
           strcmp(rPeli.pelicula, peliDelGrupo) == 0);

  // ---- cierre del grupo: semanas entre el estreno y la fecha del sistema --
  rElem.cantSemanas = CalcCantSem((int)rElem.fechaEstreno, rFecSys);

  // ---- actualizacion de la tabla de ranking -------------------------------
  if (cantPeliculas < MAX_RANK) {          // todavia hay lugar libre
    InsertaEnOrden(vrRank, rElem, cantPeliculas);
    cantPeliculas++;
  }
  else                                     // tabla llena: solo entra si supera
    if (rElem.totBoletos > vrRank[MAX_RANK - 1].totBoletos)
      InsertaEnOrden(vrRank, rElem, cantPeliculas);   // el ultimo se descarta
} // ProcPelicula
```

### Contrato de las funciones que no se desarrollan

Como no se codifican, hay que dejar escrito qué se espera de ellas:

| Función | Contrato asumido |
|---|---|
| `ushort CalcCantSem(int fechaEstreno, tsFecSys rFs)` | Devuelve las **semanas enteras** transcurridas entre `fechaEstreno` (`aaaammdd`) y la fecha del sistema: `(dias entre ambas) / 7`. Si la película se estrenó hace menos de 7 días, devuelve `0`. |
| `void InsertaEnOrden(tvrRank vrRank, tsRank elem, ushort card)` | `card` es la ocupación **antes** de insertar. Busca la posición `p` tal que `elem.totBoletos > vrRank[p].totBoletos`, desplaza hacia abajo desde el final y coloca `elem` en `p`. **Si `card == MAX_RANK` el último elemento se pierde** (es exactamente lo que se necesita al mantener un top-10). No modifica `card`: el contador lo actualiza quien la invoca. |
| `void OrdxBur(tvrRank vrRank, ushort card)` | Ordena las primeras `card` posiciones por `totBoletos` en forma **descendente**, por burbuja optimizada. |

### Variante con `OrdxBur()`

El enunciado admite `OrdxBur` **y/o** `InsertaEnOrden`. Reemplazando el último
bloque:

```cpp
  // ---- variante: agregar al final y reordenar -----------------------------
  if (cantPeliculas < MAX_RANK) {                    // hay lugar libre
    vrRank[cantPeliculas] = rElem;
    cantPeliculas++;
    OrdxBur(vrRank, cantPeliculas);
  }
  else                                               // tabla llena
    if (rElem.totBoletos > vrRank[MAX_RANK - 1].totBoletos) {
      vrRank[MAX_RANK - 1] = rElem;                  // pisa al ultimo
      OrdxBur(vrRank, cantPeliculas);
    }
```

**Cuál conviene:** `InsertaEnOrden()`. La tabla ya está ordenada, así que
insertar cuesta un solo desplazamiento; `OrdxBur()` recorre todo el array otra
vez por cada película. Con `MAX_RANK = 10` la diferencia es irrelevante en
tiempo, pero la inserción expresa mejor el invariante: *la tabla nunca deja de
estar ordenada*.

## Ejercicio 3 — `ListadoRankPeli()`

La tabla llega **ya ordenada** por el invariante que mantiene el punto 2, de
modo que este módulo sólo formatea y emite. `freopen()` redirige `cout` al
archivo pedido y lo devuelve a la pantalla al terminar.

```cpp
// ---------------------------------------------------------------------------
// Anchos de las columnas del listado (suman 101 caracteres con los separadores)
// ---------------------------------------------------------------------------
const ushort ANCHO_ORDEN   =  9;   // "nro.Orden"
const ushort ANCHO_PELI_C  = 30;   // "Pelicula"            (str30 completo)
const ushort ANCHO_BOLETOS = 12;   // "Cant.Boletos"
const ushort ANCHO_CALIF   =  8;   // "Calific."
const ushort ANCHO_FESTR   = 13;   // "Fecha Estreno"
const ushort ANCHO_SEMANAS = 19;   // "Semanas Permanencia"
const char   SEP[]         = "  "; // dos espacios entre columnas

// ---------------------------------------------------------------------------
// Convierte una fecha larga aaaammdd en la cadena "dd-mm-aaaa".
// ---------------------------------------------------------------------------
void FechaCorta(uint fechaLarga, char cadena[]) {
  ushort aaaa = (ushort)(fechaLarga / 10000);
  ushort mm   = (ushort)(fechaLarga / 100 % 100);
  ushort dd   = (ushort)(fechaLarga % 100);

  sprintf(cadena, "%02hu-%02hu-%04hu", dd, mm, aaaa);
} // FechaCorta

// ---------------------------------------------------------------------------
// ListadoRankPeli
// Emite la tabla de ranking al archivo de texto "Ranking10Peli.txt".
// vrRank YA viene ordenado por totBoletos en forma descendente: ese es el
// invariante que mantiene ProcPelicula() con InsertaEnOrden().
// cantPeli es la ocupacion real de la tabla (0..MAX_RANK).
// ---------------------------------------------------------------------------
void ListadoRankPeli(tvrRank vrRank, ushort cantPeli) {
  char cadFecha[10 + 1];           // "dd-mm-aaaa"
  uint totGeneral = 0;

  freopen("Ranking10Peli.txt", "w", stdout);   // la salida va al archivo

  // ------------------------------- titulos ---------------------------------
  cout << endl
       << "                        B O L E T E K   S . A ." << endl
       << "            RANKING DE LAS " << MAX_RANK
       << " PELICULAS MAS VISTAS" << endl << endl;

  cout << left  << setw(ANCHO_ORDEN)   << "nro.Orden"           << SEP
       << left  << setw(ANCHO_PELI_C)  << "Pelicula"            << SEP
       << right << setw(ANCHO_BOLETOS) << "Cant.Boletos"        << SEP
       << left  << setw(ANCHO_CALIF)   << "Calific."            << SEP
       << left  << setw(ANCHO_FESTR)   << "Fecha Estreno"       << SEP
       << left  << setw(ANCHO_SEMANAS) << "Semanas Permanencia" << endl;

  cout << setfill('-')
       << setw(ANCHO_ORDEN)   << "" << SEP << setw(ANCHO_PELI_C)  << "" << SEP
       << setw(ANCHO_BOLETOS) << "" << SEP << setw(ANCHO_CALIF)   << "" << SEP
       << setw(ANCHO_FESTR)   << "" << SEP << setw(ANCHO_SEMANAS) << ""
       << setfill(' ') << endl;

  // ------------------------------- detalle ---------------------------------
  if (cantPeli == 0)
    cout << endl << "*** No hay peliculas para listar ***" << endl;
  else {
    for (ushort i = 0; i < cantPeli; i++) {          // repeticion exacta 0..cantPeli-1
      FechaCorta(vrRank[i].fechaEstreno, cadFecha);

      cout << right << setw(ANCHO_ORDEN)   << (i + 1)              << SEP
           << left  << setw(ANCHO_PELI_C)  << vrRank[i].pelicula   << SEP
           << right << setw(ANCHO_BOLETOS) << vrRank[i].totBoletos << SEP
           << right << setw(5) << vrRank[i].calificacion
                    << setw(3) << ""                               << SEP
           << right << setw(ANCHO_FESTR)   << cadFecha             << SEP
           << right << setw(10) << vrRank[i].cantSemanas
                    << setw(9)  << ""                              << endl;

      totGeneral += vrRank[i].totBoletos;
    }

    // ----------------------------- pie del listado -------------------------
    cout << endl
         << "Peliculas listadas ...: " << cantPeli   << endl
         << "Total de boletos .....: " << totGeneral << endl;
  }

  freopen("CON", "w", stdout);     // devuelve cout a la pantalla
} // ListadoRankPeli
```

**Detalles importantes:**

* El **`nro.Orden` no se guarda**: se emite como `i + 1`, la posición dentro del
  array. Guardarlo sería un dato redundante que habría que recalcular en cada
  inserción.
* `setw()` afecta **sólo a la salida siguiente**, por eso se repite en cada
  campo; `setfill()` y `left`/`right`, en cambio, son **persistentes** y hay que
  reponerlos (`setfill(' ')` después de la línea de guiones).
* La cabecera y el detalle usan **las mismas constantes de ancho**, de modo que
  las columnas no pueden desalinearse.
* Requiere `#include <iomanip>` (para `setw`, `setfill`, `left`, `right`) y
  `<cstdio>` (para `freopen` y `sprintf`).
* `"CON"` es el dispositivo de consola de Windows; en Linux/macOS el equivalente
  es `"/dev/tty"`.

## Casos límite contemplados

| Caso | Comportamiento |
|---|---|
| Archivo vacío (sólo el centinela) | `main()` no entra al ciclo; `cantPeliculas = 0`; el listado emite los títulos y «No hay películas para listar». |
| Menos de 10 películas distintas | La tabla nunca se llena; el listado emite `cantPeliculas` filas, no 10. |
| Más de 10 películas | Sólo sobreviven las 10 de mayor total; el resto se descarta en `ProcPelicula()`. |
| Empate en `totBoletos` | `InsertaEnOrden()` inserta con `>` estricto, así que ante un empate **queda primera la que se procesó antes**. Con la tabla llena, un empate con el último **no entra**. |
| Película con un solo registro | El ciclo 1-x se ejecuta una vez y corta: el grupo mínimo es de un registro. |
| Última película del archivo | El `do..while` corta por el centinela, no por el cambio de clave. Por eso la condición del centinela va **primero**: en el registro centinela `rPeli.pelicula` no fue leído. |
